# Parks Report

Stats, plots, and insights relating to the state of parks in England and Wales, based on Safer Parks data.

## Navigating this repository

Notebooks beginning in numbers (e.g. `001_` etc. are working records, and not meant as final examples. Example workflow/finished notebooks do not have a number prefix.)

## Initial Stats

Calculated per-region; at a later point can think of different normalisation metrics.

- Number of parks and green spaces.
- Distribution by park type. 
- Area of green space.
